Cuatro plataformas, una misma intención

Windows, Linux y Mac ejecutan el servicio local con Muse Code instalado. Android utiliza la interfaz web y un servicio seguro que ejecute Muse. La conexión desde el teléfono y las pruebas reales en los otros equipos siguen pendientes; esta entrega solo se ha comprobado en Windows.

La detección de Muse contempla PATH y las ubicaciones de escritorio. No se declara instalado ni probado en un sistema que no hemos ejecutado.
